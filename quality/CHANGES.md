## 0.2.1

Repairs two defects found by independent review of 0.2.0, which is withdrawn as a baseline.

`quality-pin` now reads only the form `sync` writes, and refuses anything else by line. A `prek.toml` holds one
repository, each hook sets only `id` and `args`, and `git_override` sets only `module_name`, `commit`, `remote`
and `strip_prefix`. A consumer in another form must rewrite the file. `release notes` no longer reads outside the
selected tree, which `hooks/pin.sh` below does not show, because no rule defines it.

| Rule | Change | Weakening to review |
| --- | --- | --- |
| `quality-pin` | `hooks/pin.sh` changed | a definition line was removed or replaced |
