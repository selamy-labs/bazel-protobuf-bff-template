# BFF Image Release Gate & Publisher

- `gate.py`: Fail-closed exact-main GitHub Actions gate requiring `build-test`, `e2e`, `policy`, and `gate` checks bound to GitHub Actions (app `15368`) plus independent PR review rules before printing or submitting a Cloud Build release job with immutable `--handoff-uri` (`gs://<bucket>/<object>#<generation>`) and `--handoff-sha256`.
- `cloudbuild.yaml`: Runs under `${_PUBLISHER_SERVICE_ACCOUNT}` (`CLOUD_LOGGING_ONLY`) with zero Bazel builds or image rebuilds, fetching the generation-pinned credentialless qualified handoff archive via `publish-image.sh`.
- `publish-image.sh` & `verify_runtime_evidence.py`: Rejects ambient well-known ADC files, downloads the generation-pinned handoff archive via `gcloud storage cp`, verifies its exact `RELEASE_HANDOFF_SHA256`, extracts safely with no symlinks or traversal, reuses `tools/release/verify_handoff.py` (`HANDOFF.sha256`, `SHA256SUMS`, revision, OCI closure, and Docker archive layer binding), verifies complete terminal actual-container runtime acceptance (`source-revision.txt`, `command-result.json` with `exit == 0` and `witness == "actual-local-container"`, `image-identity.json` digest bindings, and Playwright `report.json` with `runtime.spec.mjs` all passing) plus the clean unsharded full `PASSED` `verify-receipt-<tag>.json` BEFORE registry authentication, configures standalone `docker-credential-gcr` with `TokenSources=["env"]`, pushes via `crane`, verifies remote digest equality, and emits a JSON release receipt.
