# Specifications

Spec Kit feature directories, one per milestone. [001](001-bff-template-foundation/spec.md) is the
umbrella spec (the "spec of specs") and holds the milestone map that the later specs trace to.

Each status is a separate claim. Deployed is no for every row; hosted CI runs on the public repository, PR #1 passed all 4 checks (`build-test`, `e2e`, `policy`, `gate`) at `f510f8e` (run `41536411991`) and `e82bc8f` (run `41542211806`) and merged to `main` at `d9f97dd`, while post-merge `main` run `41544265549` failed `policy` (`neutrality`) on the GitHub squash-merge commit metadata, and live deployment remains `no` (while ruleset `main` is active on the default branch). A qualified
result holds only for the revision and profile its evidence names.
