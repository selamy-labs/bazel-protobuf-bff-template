## Local demo (spec 012 US5)

| Claim | State |
| --- | --- |
| One command | `tools/bootstrap/bazel.sh run //tools/dev` starts the real server and the real page from `tools/dev/profile.json`, validated once by `//tools/dev/profile`, which prints every effective value with its source; `BFF_PORT`, `WEB_PORT`, `BFF_STORE` and `BFF_DATA_DIR` override one value each by name. Refused by name before anything starts: a missing, unknown or invalid value (thirteen cases in `profile_test`), a port in use, a non-numeric port, an unknown store, an unknown argument (`dev_test`) |
| Persistence, restart, reset | `store: local` keeps one file per note under the profile's directory, written atomically, owners and ids hex-encoded so nothing leaves it; a note survives a restart and another owner is refused after it; `-- --reset` removes that directory and nothing else; `store: memory` holds notes until the demo stops. The file-backed adapter and the memory fake pass the same contract suite, `bff/ports/porttest`; the local adapter's own tests cover restart, reset, escape and damaged or swapped files |
| Stop | Ctrl-C (SIGTERM) stops both children; the first child to exit ends the demo nonzero and the other is stopped; the launcher needs bash 3.2 and POSIX tools only (`dev_test`) |
| Whole-stack browser witness | `//web/e2e:local_stack_e2e_test`: the real launcher in its runfiles, the pinned browser signs in as `ana`, creates a note, opens it, reloads, opens it again; the launcher is stopped and restarted and the note is read again; `bob` is refused; a restart with `--reset` clears it. Passed on the supported Linux x86_64 profile in 996 ms end to end; the launcher reached both ports in 66, 115 and 110 ms for the three starts, measured by the witness and written beside its report (`local-stack.json`). The build before the first start is not in those numbers: a fresh checkout fetches the pinned toolchains over the network and builds first, and no offline cold start is claimed |
| Production unchanged | The production binary still refuses to start without a verifier (`config_test`, `binaries_test`); the test identity stays absent from the production bundle (`bundle_test`); the development identity is the loopback sign-in |
| Recording | Not yet recorded (T022) |
| macOS | Unverified here. An independent probe at `34e1bbc` built `//tools/dev` on Darwin ARM64 in 91 s and reached the launcher, which then exited on `wait -n` under bash 3.2; that is repaired at `6f75283`, and a native result is recorded only when the independent run records it |
