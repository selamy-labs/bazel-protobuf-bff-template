- The pin check passed a valid `prek.toml` holding the right pin and an indented local hook. It searched for one spelling of a forbidden line, and prek accepted the file. It now accepts only the one form the sync writes.
- The release notes joined a definition to the selected root without containment, and followed links, so a `..` path or a link could quote an operator's file into the notes. Every read now goes through `os.Root`.

The same fixtures also show the old check passing a hook that replaces the remote's entry and a `git_override` with `patches`, which review did not name. Both are refused now. `pin_test` and `release_test` failed on all of this before the code changed.
