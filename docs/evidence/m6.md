## Order of work

Plan, research, tasks and matrix came before code, and scratch probes came before the plan's later revisions. Red first means the test failed for its intended reason, on the code before the fix.

| Change | Red first |
| --- | --- |
| `capture` reads stdout only | Yes, three tests |
| Zero-statement report fails; real Bazel exit reaches the check; malformed branch count rejected (review of `21aafbc`) | Yes |
| Base digest uses the base's registry; `compare` applies enrollment (review of `f4bb2aa`) | Yes |
| Receipt measurement summary (review of the anchor) | Yes |
| Legs, CI, merger, evaluator, base naming, hook setting | Written with their tests, and not claimed red first |

Found by a rehearsal in a disposable clone, the first real base build: Bazel's `//...` walked into the base worktree under `.git`, and `toolchain-fixtures` failed on a link there. The M5 push worktree has the same exposure. `REPO.bazel` now ignores `.git`, with a control.

Found by running real tools, not by a test written first: `.bazelrc` parsing consumed the filter's backslash, so the quality module was silently uninstrumented; Bazel calls the report
generator with other arguments; the `e2e` leg's subtraction would have removed its own targets; prek gives a new branch a real `--from`.

## Coverage marker witness (S005)

Measured with the pinned Node 24.22 over one file with an untested branch, in lines hit of 10:

| Marker | Lines hit | Effect |
| --- | --- | --- |
| None | 5 | Control |
| `/* node:coverage ignore next 3 */` | 8 | Hides code |
| `/* node:coverage disable */` | 9 | Hides code |
| `c8 ignore next`, `istanbul ignore next`, `v8 ignore next` | 5 | No effect under this runner |
| A line comment, no spaces, or split across lines | 5 | No effect |

S005 bans the two that work and keeps the older spellings, which a tool change could revive. Go has no comment that hides a statement from `go test -cover`.

## Results that were not credited

- The first `pure = "on"` build left a stale `floors` binary in `bazel-bin`, and one all-absent measurement came from it. It failed closed. Removing the transition ended it. `f4bb2aa` therefore cannot build as a base, which is harmless.
- The first probes reported empty TypeScript coverage partly because the probe's merger read only `*.dat`. Research records the corrected attempts.
- Early research called the quality module 72 to 75 percent from an LCOV path match. Neither number is used.
