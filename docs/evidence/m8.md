## Results that were not credited

- The first external neutrality and inventory drafts passed their own 17 and 9 fixtures and failed root's synthetic controls and an independent review on five counts: a large blob missed through a pipeline, a marker printed as an email domain, a whitespace-only marker file read as a pass, an empty license cell read as complete, and paths read from a deduplicated listing. Each has a fixture now.
- `99d738f` bound the inventory check while it failed on the tree for `LICENSE`; the next commit fixed the boundary.
- A governance fixture edited the source tree through a runfiles link before the copies dereferenced links; the files were restored from the formatted draft and the test asserts the source is untouched.
- The full verifier at `4e7ccaf` failed on `neutrality` alone, on the literal blob above; 27 other checks passed. A history rewrite was started to remove that blob and aborted before any ref moved, in favor of the recorded decision.
- The reflog-only private-identity commit was pruned before its bundle was confirmed; the bundle command had refused a bare object id. The object is not preserved, and 754 repository copies and every bundle on the host were checked without finding it.
- The full verifier at `94d226c` failed on `neutrality` alone, on the second literal blob; 28 other checks passed. Earned nothing.
- At `94d226c` the decided-finding line printed the allowlist's reason text, which an independent probe showed could carry a private term. The reference-only output replaced it, with a reason-containing-marker control.
- The full verifier at `00a4c6b` passed, 29 checks; it predates this fix and the executed checklist, so the candidate's own gate is the later one.
- Until `94d226c` the author checkout had no installed hooks, and commits ran the pre-commit stage by hand. The canonical installer put them in place afterwards, and a snapshot clone proved a gofmt defect rejected and a clean commit passed through the real hook; commits from then on go through it.
