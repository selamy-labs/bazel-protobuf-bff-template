# Provenance and License Inventory

Every third-party or reference-derived item in this repository is listed here, in three scopes: the source
export, built artifacts, and tools used only to build or test. An entry is a table row whose `Identifier` cell
names what the pin names, and `tools/release/inventory.sh` fails on a pinned identifier with no row. A License
cell that says `unresolved: <reason>` is an explicit open finding and never a permissive reading; a release
review needs each such row decided. This inventory is metadata for review, not a legal or compliance judgment.
"Pattern-only" means an idea was learned from a source; no code, schema, configuration value, fixture,
identifier or prose was copied.

## First-party prose boundary

This repository's own documentation quotes license names and copyright wording. The inventory check does not
treat these paths as vendored material: `LICENSE`, this repository's own license; `docs/**`, `specs/**`,
`README.md`, `AGENTS.md`, `*/README.md`, `.specify/memory/constitution.md`. Everything else that carries a copyright or license marker must be under an
enrolled vendored path below.
